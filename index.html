伊那谷の歴史　ショート動画の予約投稿ツール（個人用）

このツールについて

地域アカウント「伊那谷の歴史」の運営者が、自分で作った縦長の短い動画を、自分の YouTube チャンネルと TikTok アカウントに投稿するための個人用ツールです。一般向けに提供しているサービスではなく、利用者はアカウントの運営者だけです。

できること

  • 自分のチャンネルの情報（チャンネル名・ID・登録者数・動画数）の確認
  • ショート動画のアップロードと公開日時の予約
  • Threads に動画を投稿するための、Google ドライブへの一時的な動画の配置と削除
  • 自分の TikTok アカウントへの動画の投稿（下書きへの送信、または公開設定を選んでの投稿）

使用している TikTok のサービス

TikTok の Login Kit と Content Posting API を使用します。運営者本人が TikTok アカウントで許可した範囲でのみ、本人のアカウントに動画を投稿します。投稿の前に、キャプション・公開範囲・コメントなどの設定を運営者が確認します。

使用している Google のサービス

YouTube Data API v3 と Google Drive API（Google の公式API）を使用します。運営者本人が Google アカウントで許可した範囲でのみ、本人のチャンネルと、本ツールが作成したドライブのファイルにアクセスします。

プライバシーポリシー

取り扱う情報と保存方法は プライバシーポリシー、利用の条件は 利用規約 をご覧ください。
