プライバシーポリシー

inadani-shorts（伊那谷の歴史　ショート動画の予約投稿ツール）

1. このツールの利用者

本ツールは、地域アカウント「伊那谷の歴史」の運営者が、自分のチャンネルを管理するためだけに使う個人用ツールです。一般の方の情報を集めることはありません。

2. 取得する情報

運営者が Google アカウントで許可した範囲で、YouTube Data API と Google Drive API を通じて次の情報を扱います。

  • Google の認証情報（アクセストークン・更新トークン）
  • 運営者のチャンネルの情報（チャンネル名・チャンネルID・登録者数・動画数）
  • 運営者がアップロードした動画の情報（動画ID・タイトル・公開予定日時）
  • 本ツールが Google ドライブに作成したファイルの情報（ファイルID・ファイル名）。本ツールが作成していないファイルにはアクセスしません

運営者が TikTok アカウントで許可した範囲で、TikTok の Login Kit と Content Posting API を通じて次の情報を扱います。

  • TikTok の認証情報（アクセストークン・更新トークン）
  • 運営者の TikTok アカウントの基本情報（表示名・アイコン・ユーザーID）
  • 運営者が投稿した動画の情報（投稿ID・処理の状態）

3. 利用目的

  • ショート動画のアップロードと、公開日時の予約
  • 投稿先のチャンネルが正しいかの確認
  • Threads に動画を投稿するための、Google ドライブへの一時的な動画の配置（読み込みが終わったらすぐ削除します）
  • 運営者の TikTok アカウントへの動画の投稿（下書きへの送信を含む）

上記以外の目的（広告・分析・販売など）には使用しません。

4. 保存場所と第三者への提供

取得した情報は、運営者自身のパソコンの中にだけ保存します。Google と TikTok の API との通信を除き、外部のサーバーに送信・保存することはなく、第三者に提供・共有することもありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. アクセスの取り消しと情報の削除

本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」から、TikTok は アプリの「設定とプライバシー」→「セキュリティ」→「アプリの権限」から、いつでも取り消せます。パソコンに保存した認証情報は、本ツールのフォルダから削除することで消去されます。
